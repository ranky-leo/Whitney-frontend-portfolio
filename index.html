Practice

Frontend, designed and built.

01

Lumen Press

2010 — 2014 · Editorial

The reading page was the product. I designed the measure, the caption, and the crop for every plate, then built the templates so an editor could not publish a hero that broke the ratio or sat on the wrong ground. The guide was the layout. That is where the habit of a definitive visual call started.

Role
Design and frontend
Designed
Article template, plate crop, caption, type scale
Built
HTML and CSS templates, a ratio lock, a ground color that rejected an off-palette frame

02

Northwharf

2014 — 2018 · Product

An operations console for a freight desk. The screens were dense, and the visual system had to stay quiet while the data did not. I designed the hierarchy and built the React set behind it: tables, filters, empty states, and one red reserved for a decision. Focus order, contrast, and a name on every control were part of the layout, not a pass at the end.

Role
Product design and frontend
Designed
Information hierarchy, status, empty states, the quiet palette
Built
React component library, TypeScript as the surface grew, accessible controls

03

Calder Goods

2018 — 2021 · Commerce

Product photography was the page. I designed the gallery, the still-life crop, and the type that sits in the open space, then built it in Next.js so the rule was code. Left third, warm ground, label held — or the frame did not ship. The prettier photograph lost when it broke the guide.

Role
Design and frontend
Designed
Gallery, crop, type beside the product, brand color
Built
Next.js storefront, image component, tokens for color and ratio

04

Common Room

2021 — 2026 · Design system

One system across four product surfaces. I designed the type scale, the space scale, and the color and image rules for each brand, then built them in React and TypeScript. A new surface could theme the color. It could not invent a second crop, a second highlight, or a type size that was not on the scale. The documentation lived next to the components.

Role
Design engineering
Designed

Built
React and TypeScript library, shared tokens, docs beside the code

Baseline

The rules, applied without softening.

01

Light

Direction, number of sources, clipped highlights, and whether the shadow describes the form.

02

Composition

Placement, crop, negative space, and whether the frame still leaves room for type.

03

Focus

The plane of sharpness belongs on the thing that matters. Blur may not compete with it.

04

Brand

Palette, ratio, clear space, prohibited treatments. A beautiful frame that breaks the guide loses.

Close pairs still have a winner. I pick it and I write the reason.

Selected decisions

The same call, in the work.

01

One light, left third

A still-life guide allowed a warm-neutral ground and a product set off center so the wordmark had room. Frame A fails it: centered on a cool gray, label clipped toward white, no open side. Frame B is the file that leaves the studio. The rule then lives in the layout — a crop component and a ground token — so the next frame cannot drift back to center.

02

Focus where the face is

The editorial rule is short. Eyes sharp. Hair inside the frame. Clear space kept on the side the type will use. A holds all three. B is the tighter crop and the wrong one: the head sits on the right edge, the empty field falls on the left, and the collar starts to compete. On a product surface the same rule decides the hero. The face, or the label, keeps the quiet side.

03

The palette is the standard

The dramatic frame was available. The guide did not ask for it. A puts a cyan cast in the shadow, blows the window, and cuts the hand. B keeps the wall on the brand neutral, gives the figure a horizon, and leaves the gesture whole. In the interface that choice is a color limit, not a mood. If the shadow leaves the neutral, the image does not ship.

About

Fifteen years on the visual layer.

Whitney Clarke is a senior designer-engineer. The work is frontend design and the engineering that keeps a visual standard in place: which photograph is chosen, which crop survives a brand guide, and which rule the interface is willing to enforce.

Judging a pair against a written baseline is the same decision, made in the open. One winner. The reason in a few sentences. No softening when the prettier frame breaks the guide.
